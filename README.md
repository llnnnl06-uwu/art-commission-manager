# Art Commission Studio
  เว็บแอปพลิเคชันสำหรับการจัดการคิวงานคอมมิชชันแบบ Full-Stack
  มีการใช้ Node.js + Express + Vanilla JS

# วิธีติดตั้งและรัน
1. ติดตั้ง Dependencies >> npm install
2. รันเซิร์ฟเวอร์ >> npm run dev หรือ node server.js
3. เปิดหน้าเว็บโดยใช้ >> http://localhost:3000

# REST API Endpoints
- GET / api /commissions
- GET / api /commissions / :id
- POST / api /commissions
- PATCH / api /commissions / :id
- DELETE / api /commissions / :id
